Fortschrittscodes einfügen

Im Spiel: ☰ → 🎓 Lehrkraft & Klasse → Fortschritt abgeben. Die Codes (beginnen mit ATC1.) hier hineinkopieren – beliebig viele auf einmal, z. B. alle Abgaben aus OPAL. Neuere Codes ersetzen ältere desselben Namens. Gespeichert wird nur in diesem Browser.

Klasse

Zellen: gelöste Hauptaufgaben je Kapitel (🟩 fertig, 🟨 angefangen). Maus auf eine Zelle zeigt, was fehlt. Graue Zeile = Code älter als 7 Tage.

Code erstellen

Codes gelten nur heute und lassen sich in jedem Spielstand einmal einlösen. Im Spiel: ☰ → 🎓 Lehrkraft & Klasse → Code eingeben (Burgen: auch direkt in der Burgwahl).

Gemeinsames Klassenziel

Alle ⭐ der Klasse (aus den eingefügten Fortschrittscodes dieser Burg) zählen zusammen – niemand verliert, jeder Stern hilft. Ist das Ziel erreicht, gibt es eine Belohnung für alle, z. B. einen 🎁 Gold-Code.
